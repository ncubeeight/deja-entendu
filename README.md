Déjà Entendu is a utility to help language students practice terms they have overheard, whether in class, in family conversations or their own speech.
The app does not contain an LLM in the code. Instead it uses the Foundation Model LLM resident on any iPhone after model 15.
To preserve privacy there is no login or account system. The app runs locally and draws on local resources.
This tool can be forked and compiled into other apps that a developer may want to build to interpret languages.
The number of languages currently supported by Apple's on-device LLM limits the function of the audio transcription and flashcard generation.
As Apple LLM expands to more languages, the basic Déjà Entendu app can also be expanded to parse with those languages.
Known issue from testing is that audio parsing does not work well with extensive background noise in the recording. 
Other developers may build off this app as a fork and use their own branding and features without re-committing to this code base.
